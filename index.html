    Ask the data anything.

    Type a question in plain English. An AI model running on Groq writes the SQL, the query is checked, then it runs against the cleaned permit tables in Databricks.

    1. Your question is turned into a SQL query
    2. The query is checked before anything runs
    3. Databricks runs it and the answer comes back with the SQL, so you can check exactly what ran

    About the numbers. Counts include main permits and standalone trade jobs. Plumbing, drain and HVAC permits attached to a larger project are left out so the same project is not counted twice.

    Construction values are declared by applicants and may understate real spending. Homes created excludes cancelled permits. Median approval times stop at 2024 because many recent applications are still in review. Permits without a usable postal code are grouped as unknown area.

    Source: City of Toronto Open Data, building permits (active and cleared).

    Pipeline: Azure Data Lake, Databricks Delta Lake and a star schema, served from permits.gold.ui_summary.
